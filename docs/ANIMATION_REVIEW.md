# Homepage motion review

The former WebGL house sequence has been removed with the retired homepage renderer. The current website uses scroll-linked image parallax, restrained perspective movement, offset hero elements and once-only section reveals. Native page scrolling remains uninterrupted; reduced-motion preferences keep all content visible and remove spatial movement.

The animation implementation and responsive checks are documented in [WEBSITE_DESIGN.md](WEBSITE_DESIGN.md). The Editor's optional solar animation remains in [the Editor design notes](COURTYARD_DESIGN.md).
