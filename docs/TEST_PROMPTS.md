# Generation acceptance prompts
Run `npm run test:prompts`. The script generates a new home per prompt through the offline engine and validates the shared model. Hosted model integration requires credentials and is covered separately by mocked service tests.

1. Create a 120 sqm home with 2 bedrooms and 1 bathroom
2. Generate a 150 sqm house with 3 bedrooms and 2 bathrooms
3. Build a minimal 100 sqm apartment with 2 bedrooms and 1 bathroom
4. Design a 180 sqm home with 4 bedrooms and 2 bathrooms
5. Create a 90 sqm house with 1 bedroom and 1 bathroom
6. Создай дом 120 м² с 2 спальнями и 1 ванной
7. Спроектируй квартиру 150 м² с 3 спальнями и 2 ванными
