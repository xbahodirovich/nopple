# Mopple design review

> This records the previous design-polish pass. The 7 October local Studio extension follows the same black/mint identity and is documented in [STUDIO_RELEASE.md](STUDIO_RELEASE.md).

Reviewed the merged main branch across the landing page, editor, reviewed brief, render gallery, sun study, empty/populated home library, and public share page. Preserved the existing black/mint identity, Inter typography, offline engine, and reversible scroll-driven house demonstration.

## Skills and scope

Applied Impeccable for product usability and responsive polish; design-taste-frontend (the installed Taste skill) for the landing page; Emil design engineering for interaction details; and review-animations for the final motion review. Landing direction: a practical home-design tool for homeowners and renters, with clear copy and a restrained architectural presentation. Working dials: variance 5, motion 4, density 3. Existing brand decisions take precedence over generic font or layout defaults.

No installed Humanizer skill or connected 21st MCP was available. Local skill discovery and plugin search found neither. Copy was edited directly for plain language; no external component or Humanizer integration is claimed.

## Findings and changes

| Finding | Result |
| --- | --- |
| Landing CTA led into the demonstration instead of starting a home | Primary CTA opens the editor; the demonstration remains independently available |
| Promotional/technical language obscured the workflow | Shorter factual copy, clear audience, before/after example, honest concept and Pro labels |
| My homes lacked a usable layout and could inherit the editor's hidden overflow | Scrollable library, readable dates, empty state, responsive actions and version selector |
| Share page had minimal framing and no accessible perspective controls | Branded read-only header, orbit instructions, Exterior/See inside/Top view buttons with pressed state |
| Mobile dialogs and gallery controls were cramped | Larger targets, wrapped actions, clearer hierarchy and scrolling content |
| Sun panel competed with the mobile prompt and ran after closing | Full-height mobile overlay, hidden underlying prompt, explicit Close/Play/Pause, playback stopped when closed/hidden |
| Decorative emoji and raw identifiers weakened clarity | Consistent furniture markers, resolved room names and plain labels |
| Broad transitions affected repeated studio actions | Instant studio states; bounded landing feedback and reduced-motion behavior |
